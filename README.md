# Tevin Garrett: IT Support Portfolio

A small portfolio site with a home page, a filterable Resume, and a contact form. Plain HTML, CSS, and JavaScript.


## Understanding the Project Requirements

 Requirements.

 3 HTML pages, one a landing page `index.html` landing page, links to the other two, `resume.html`, `contact.html`

 3 JS files, one per page `js/index.js`, `js/resume.js`, `js/contact.js` 
 
 A CSS file linked to all pages `css/styles.css`, linked in the `<head>` of every page 
 Organized, well-named files `css/`, `js/`, and `docs/` folders; each JS file is named after its page 
 
 Document the design process  This file, plus the wireframes in `docs/` 


## Files

index.html      Home/Landing page: intro, service cards, IT tip button
resume.html     Resume with category filter buttons
contact.html    Contact form and common questions
css/styles.css  One stylesheet used by all three HTML pages
js/index.js     Builds the service cards and cycles the tips
js/resume.js    Resume data in an array of objects and the filter
js/contact.js   Form checks and the question list
DESIGN.md       Design process
